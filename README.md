# روح وحياة — Spirit & Life

رحلة قراءة سفر التكوين (أصحاح كل يوم، ما عدا الجمعة) لموظفي مستشفى هرمل بمدينة السادات، من الأربعاء ٢٥ نوفمبر ٢٠٢٦ لحد الخميس ٢١ يناير ٢٠٢٧ (٥٠ يوم).

> «الكَلامُ الَّذي أُكَلِّمُكُمْ بهِ هو روحٌ وحَياةٌ» (يوحنا ٦: ٦٣)

- موقع ثابت (HTML + JavaScript modules) من غير framework، بيشتغل كـ PWA على الموبايل.
- البيانات على Firebase (Anonymous Auth + Firestore). القواعد في `firestore.rules`.
- لوحة المسؤولين: `/admin/` (أو `#/admin`)، بكود بيتحدد مرة واحدة من الموقع.
- وضع تجريبي: أضف `?demo` للينك (البيانات على الجهاز بس)، و`?date=YYYY-MM-DD` لمحاكاة أي تاريخ.
- نص التكوين: ترجمة فان دايك (ملك عام).
